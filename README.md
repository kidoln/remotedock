## 🚀 Quick Start / 快速开始

### System Requirements / 系统要求

- **Mac**: macOS 14.0 or later / macOS 14.0 或更高版本
- **iPhone**: iOS 17.6 or later / iOS 17.6 或更高版本
- Both devices on the same local network or Apple Peer-to-Peer / 双端设备在同一局域网或开启 Apple 近距连接

### Pairing Process / 配对流程

1. **Launch Remote Dock for Mac** / 在 Mac 上启动 Remote Dock for Mac

2. **View Pairing Code** / 查看配对码
   - The 4-digit code appears in your Mac menu bar / Mac 菜单栏显示 4 位配对码

3. **Open Remote Dock on iPhone** / 在 iPhone 上打开 Remote Dock

4. **Enter Pairing Code** / 输入配对码
   - Enter the code shown on your Mac / 输入 Mac 上显示的配对码
   - Connection is automatic / 输入完成后自动连接

5. **Connected!** / 连接成功！

## 🔧 Troubleshooting / 故障排除

### Cannot discover Mac? / 无法发现 Mac？

**Solutions / 解决方法**:

- Ensure both devices are on the same Wi-Fi / 确保在同一 Wi-Fi
- Check if Remote Dock for Mac is running / 检查 Mac 端是否运行
- Check Mac firewall settings / 检查 Mac 防火墙设置

### Cannot paste to Mac? / 无法粘贴到 Mac？

**Solutions / 解决方法**:

- Grant Accessibility permission on Mac / 在 Mac 上授予辅助功能权限
  - System Settings → Privacy & Security → Accessibility
  - Find Remote Dock and enable / 找到 Remote Dock 并启用

### Clipboard not syncing? / 剪贴板不同步？

**Solutions / 解决方法**:

- Confirm clipboard sync is enabled on Mac / 确认 Mac 端剪贴板同步已启用
- Check connection status / 检查连接状态
- Try reconnecting / 尝试重新连接

## ❓ FAQ / 常见问题

### Is Remote Dock free? / Remote Dock 是免费的吗？

**Mac version**: Completely free / **Mac 版本**：完全免费

**iOS version**: Basic features free, advanced features require one-time purchase / **iOS 版本**：基础功能免费，高级功能需一次性购买

### Need internet connection? / 需要互联网连接吗？

No. Just local network or Apple Peer-to-Peer / 不需要。只需本地网络或 Apple 近距连接

### Can I connect to multiple Macs? / 可以连接多个 Mac 吗？

Currently one Mac at a time. Disconnect to switch. / 目前一次只能连接一个 Mac。断开后可切换。
