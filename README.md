## 关于 Remote Dock

Remote Dock 是一款专为 Apple 生态设计的效率工具，让 iPhone 成为 Mac 的完美伴侣。

- **功能**：远程切换 Mac 应用、同步剪贴板历史
- **隐私**：所有数据仅在本地网络传输，不收集任何用户数据
- **开源**：[https://github.com/kidoln/remote-dock](https://github.com/kidoln/remote-dock)
