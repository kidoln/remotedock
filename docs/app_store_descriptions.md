#### 详细描述（4000 字符限制）

```
Remote Dock 是一款专为 Apple 生态设计的效率工具，让你的 iPhone 成为 macOS 的完美伴侣。

【核心功能】
• 快速切换 Mac 应用 —— 从 iPhone 上一键切换 Mac 上正在运行的应用
• 剪贴板历史同步 —— 实时查看 Mac 剪贴板历史，一键粘贴到当前应用
• 常用应用管理 —— 在 Mac 上配置常用应用，iPhone 端即时同步
• 本地网络连接 —— 通过局域网或 Apple 近距连接，无需云端

【使用场景】
工作时快速在多个应用间切换；从手机上查看 Mac 剪贴板历史内容；远程粘贴文本到 Mac 前台应用。

【注意事项】
需要在 Mac 上配合安装 Remote Dock for Mac 使用，双端设备需在同一局域网或开启 Apple 近距连接。部分功能需要 Mac 授予辅助功能权限。

【隐私承诺】
所有数据仅在同一局域网传输，不经过云端服务器；不收集任何用户数据；剪贴板内容仅在本地存储。
```

#### Detailed Description (4000 characters max)

```
Remote Dock is an efficiency tool designed for the Apple ecosystem, making your iPhone the perfect companion for your Mac.

【Key Features】
• Quickly switch Mac apps — Switch between running Mac apps with one tap on your iPhone
• Clipboard history sync — View Mac clipboard history in real-time, paste with one tap
• Pinned apps management — Configure frequently used apps on Mac, sync instantly to iPhone
• Local network connection — Connect via LAN or Apple Peer-to-Peer, no cloud required

【Use Cases】
Quickly switch between multiple apps while working; View Mac clipboard history from your phone; Remotely paste text to the frontmost Mac app.

【Requirements】
Requires Remote Dock for Mac installed and running on your Mac. Both devices must be on the same local network or have Apple Peer-to-Peer enabled. Some features require Accessibility permission on Mac.

【Privacy Commitment】
All data transmitted only on local network, no cloud servers; No user data collection; Clipboard content stored locally only.

```
Remote Dock for Mac 是 Remote Dock 的 macOS 宿主端应用，需与 iOS 版本配合使用。

【核心功能】
• 与 iPhone 配对连接 —— 通过配对码建立安全连接
• 共享常用应用列表 —— iPhone 端即时同步 Mac 常用应用
• 同步运行中应用状态 —— 实时显示 Mac 正在运行的应用
• 共享剪贴板历史 —— iPhone 可查看并远程粘贴 Mac 剪贴板内容
• 执行远程命令 —— 响应来自 iPhone 的应用切换和粘贴命令

【使用方法】
1. 在 iPhone 上安装 Remote Dock
2. 确保双端在同一网络
3. 在 Mac 上启动应用，查看配对码
4. 在 iPhone 上输入配对码完成连接

【权限说明】
• 辅助功能权限：用于切换应用和模拟粘贴操作
• 本地网络权限：用于发现和连接 iPhone
• 蓝牙权限：用于 Apple 近距连接

【隐私承诺】
所有数据仅在同一局域网传输，不经过云端服务器；不收集任何用户数据；剪贴板内容仅在本地存储。

【免费说明】
本应用完全免费，无任何内购或广告。
```

```
Remote Dock for Mac is the macOS host app for Remote Dock, designed to work with the iOS version.

• Pair and connect with iPhone — Establish secure connection via pairing code
• Share pinned apps list — iPhone instantly syncs frequently used Mac apps
• Sync running apps status — Real-time display of running Mac apps
• Share clipboard history — iPhone can view and remotely paste Mac clipboard content

2. Ensure both devices are on the same network
3. Launch the Mac app and note the pairing code
